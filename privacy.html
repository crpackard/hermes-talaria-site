Hermes-Talaria privacy policy

Last updated 28 September 2026

Who uses it

Hermes-Talaria is a single-user application operated by its developer, Charles Packard, for his own Google account. It is not offered to other users.

What it accesses

With the owner's consent, it uses Google APIs to read and modify Gmail messages and labels, calendar events, contacts, Google Tasks, and Google Drive files, only when the owner asks it to in a chat.

Where data goes

Google data is processed by software running on the owner's own computer, including a language model that runs locally. Access tokens are stored on that computer. Google user data is not sold, is not used for advertising, and is not transferred to anyone else. It is not used to train or improve general-purpose AI models. Coding assistants used to develop the application work on its source code, not on Google user data.

Retention and deletion

Data read from Google stays on the owner's computer, in chat history the owner can delete from the app. Access can be revoked at any time at myaccount.google.com/permissions, which stops all further access.

Google policy

Hermes-Talaria's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
